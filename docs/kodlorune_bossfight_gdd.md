# KODLORUNE — Game Design Document (GDD)
## Битва з «ПОДРО» та Система Семи Душ

---

## 1. Загальний огляд концепту

* **Жанр:** 2D Bullet Hell / RPG Boss Encounter (натхненно *Deltarune* та *Undertale*).
* **Головний референс:** Битва з **Flowery** (Deltarune Chapter 5).
* **Ключова особливість:** Замість фіксованої механіки арени кожен етап битви змінює колір душі гравця на один із 7 режимів, водночас викликаючи помічників-хуманізацій, які змінюють темп, правила колізій та жанр ухиляння.
* **Послідовність режимів душ:**
  $$\text{Red} \longrightarrow \text{Yellow} \longrightarrow \text{Green} \longrightarrow \text{Blue} \longrightarrow \text{Orange} \longrightarrow \text{Purple} \longrightarrow \text{Aqua}$$

---

## 2. Візуальна сцена та Арена («Тепер вигляд»)

```
+--------------------------------------------------------------+
|                     [ПАРАЛАКСНИЙ ФОН]                        |
|                                                              |
|        [Трибуна Сапортів]                [Трибуна Сапортів]  |
|                                                              |
|                     +------------------+                     |
|                     |                  |                     |
|                     |  БОЙОВА КОРОБКА  |                     |
|                     |     (2D ARENA)   |                     |
|                     |                  |                     |
|                     +------------------+                     |
|                                                              |
|                 [3D ОБЕРТОВИЙ МОНУМЕНТ КАБАНА]               |
|                     (Low-Poly / Flat-Shaded)                 |
+--------------------------------------------------------------+
```

### 2.1. 3D-монумент Кабана
* **Суть:** Величний, низькополігональний (PS1/retro low-poly) кабан, що безперервно й велично обертається навколо своєї осі в центрі фону.
* **Символізм:** Німий спостерігач, древній монумент та істинний тотем сили Кодла. Він не втручається в бій, але створює відчуття епічного святилища.
* **Технічна реалізація в Godot 4:** Окремий `SubViewport` з `Camera3D` та `MeshInstance3D`, що транслюється через `ViewportTexture` на задній шар 2D-сцени з легким піксельним шейдером.

### 2.2. Сапорти на трибунах
* Розташовані по боках арени на ширяючих платформах.
* Помічник змінюється при кожній зміні душі, супроводжуючи перехід анімацією виходу, фірмовою реплікою та реакціями на дії гравця.

## 3. Протагоніст та Антагоністи

### 3.1. Головний Бос: «ПОДРО» (The "Ideal" Podro)
* **Концепція:** Стерильна, штучно-ідеалізована версія Подро (як Flowey ➔ Flowery). Він не робить дурниць, не матюкається, п'є «правильну каву без осаду» і щиро переконаний, що справжній хаотичний Подро — це ганьба, яку слід стерти.
* **Зовнішність:** Білосніжний смокінг, застигла порцелянова посмішка (*Winning Smile*), золоті запонки у вигляді кавових зерен, над головою — німб із ароматної пари еспресо.
* **Фаза 1:** Виходить на бій **абсолютно сам** під класичну Червону душу, доводячи свою самовпевнену вищість.

---

### 3.2. Шість Помічників (Хуманізації Речей Подро)
Аналоги квітів з 5-го чаптера Deltarune, створені з пам'ятних предметів лору:

| Душа | Помічник | Річ-прототип | Прототип Deltarune Ch.5 | Характер |
| :--- | :--- | :--- | :--- | :--- |
| **💛 Yellow** | **Золотий Ковбой** | Банка Nescafe Gold | *Yellow* (ковбой правосуддя) | Пафосний сноб, вершить «суд преміального помелу». |
| **💚 Green** | **Мідний Шеф** | Турка Подро | *Green* (ображений шеф-кухар) | Ображений на залишену брудну плиту, захищає комбінації 8 сторін. |
| **💙 Blue** | **Балерино-мішалка** | Дерев'яна ложка | *Blue* (слизький балерино) | Естет піруетів, зневажає незграбність, роздвоює душу. |
| **🧡 Orange** | **Торпеда** | «Торпеда буття» (ПЕТ) | *Orange* (реактивне мишеня) | Бойовий шибайголова на реактивній тязі, боїться розбитися, вчить апексам. |
| **💜 Purple** | **Сет** | Мобільник / Пейджер 22:00 | *Seth* (стратег в окулярах) | Бухгалтер дедлайнів, прораховує кроки на сітці під таймер. |
| **🩵 Aqua** | **Аква-пустунка** | Бутель кар'єрної води | *Aqua* (нетерпляча дівчинка) | Гіперактивна бешкетниця, затоплює арену, кричить пірнати й злітати. |

## 4. Специфікація Режимів Душ та Фаз Битви

### 4.1. Фаза 1: ❤️ Red Soul (Червона — «Подро» Наодинці)
* **Правила руху:** Вільне двовимірне переміщення у прямокутній коробці зі стабільною швидкістю.
* **Атаки «Подро»:**
  * *«Ідеальна температура (95°C)»:* Тонкі лазерні попереджувальні лінії, що через 0.6 с детонують у геометрично вивірені промені.
  * *«Цукор без гіркоти»:* Квадратні блоки рафінаду падають зверху і розколюються на 4 симетричні осколки при контакті з підлогою.

---

### 4.2. Фаза 2: 💛 Yellow Soul (Жовта — Золотий Ковбой)
* **Правила інпуту:**
  * Серце повернене верхівкою догори.
  * `Primary Attack (Z / J / Tap):` Швидкий одиночний постріл. Знищує **тільки жовті проджектайли**.
  * `Charge Attack (Утримання > 0.8с):` Заряджений плазмовий згусток кавового золота. Знищує будь-які звичайні ворожі кулі в радіусі вибуху.
* **Атаки Ковбоя та «Подро»:**
  * *«Жовтий лабіринт»:* Суцільні стіни червоних куль з рідкісними ланцюжками жовтих. Гравець мусить точково вибивати жовті кулі, щоб пробити собі шлях.
  * *«Золота кришка»:* Масивний непробивний диск котиться ареною — його можна знищити лише прямим Charge Shot.

---

### 4.3. Фаза 3: 💚 Green Soul (Зелена — Мідний Шеф)
* **Правила інпуту:**
  * Серце зафіксоване в центрі коробки, рух вимкнено.
  * Щит повертається у **8 напрямках** (↑, ↓, ←, →, ↗, ↘, ↙, ↖) за допомогою стрілок/стіка.
* **Атаки Шефа та «Подро»:**
  * *«Киплячі комбінації»:* Снаряди летять у ритм музики з 8 векторів. Потребує швидкого перемикання щита.
  * *«Дуговий вигин»:* Снаряди змінюють траєкторію за 0.2 с до зіткнення, змушуючи зчитувати діагональний фінальний кут.

---

### 4.4. Фаза 4: 💙 Blue Soul (Синя — Балерино-мішалка)
* **Правила інпуту:**
  * Гравітація тягне серце донизу. Кнопка `Up / Jump` дає стрибок змінної висоти (залежно від тривалості натискання).
  * **Механіка «Поділ Душі»:** Серце розпадається на два незалежних об'єкти (Soul A і Soul B), які рухаються симетрично або паралельно.
* **Атаки Балерино та «Подро»:**
  * *«Обертові лопаті»:* По підлозі рухаються лопаті-мішалки різної висоти.
  * *«Двоповерховий вальс»:* Для Soul A небезпека знизу (треба стрибнути), а для Soul B — небезпека зверху (треба залишитися внизу).

---

### 4.5. Фаза 5: 🧡 Orange Soul (Помаранчева — Торпеда Буття)
* **Правила інпуту:**
  * Фізика дрифту та інерції: `velocity = velocity.lerp(target_velocity, friction * delta)`.
  * По кутах та краях арени розташована **Трава** (`Grass Area` за зразком Mario Kart).
  * При заїзді на траву: тертя зростає в 4 рази, швидкість падає на 75%, вихід з заносу стає в'язким.
* **Атаки Торпеди та «Подро»:**
  * *«Таранний пуск Торпеди»:* Торпеда стартує з вихлопом через усю арену, рикошетячи від стін.
  * *«Спідометр смерті»:* З центру обертається лазерний промінь, що змушує дрифтувати навколо перешкоди по чистому треку, не вилітаючи на траву.

---

### 4.6. Фаза 6: 💜 Purple Soul (Фіолетова — Сет-стратег)
* **Правила інпуту:**
  * Арена перетворюється на дискретну сітку (Grid 5x5 або 7x7). Прямий рух стрілками заблоковано!
  * Відкривається термінал команд:
    * `Z` — Крок вперед (`FORWARD`).
    * `X` — Поворот на 90° ліворуч (`TURN_LEFT`).
    * `C` — Поворот на 90° праворуч (`TURN_RIGHT`).
    * `Accept (Enter / Up)` — Запуск виконання черги.
  * **Таймер детонації:** Гравець має 5.0 секунд, щоб ввести коректну послідовність дій і запустити її.
* **Атаки Сета та «Подро»:**
  * *«Квадратний вибух»:* На сітці заздалегідь підсвічуються червоні зони ураження. Потрібно спланувати маршрут серця у безпечну зелену зону до закінчення таймера.

---

### 4.7. Фаза 7: 🩵 Aqua Soul (Аква — Аква-пустунка)
* **Правила інпуту:**
  * Арена наповнена водою.
  * **Плавучість:** Сила виштовхування плавно тягне серце до поверхні води.
  * Кнопка `Down` — занурення на дно з подоланням опору води.
  * **Стрибок Дельфіна:** При різкому виході з глибини до поверхні з утриманням `Up` накопичений вертикальний імпульс викидає серце високо в повітря над водою.
* **Атаки Пустунки та «Подро»:**
  * *«Глибинні торпеди»:* Горизонтальні залпи під водою.
  * *«Поверхневий шторм»:* Лазери та вогонь над водою.
  * *«Хвиля-Цунамі»:* Велетенська стіна на всю висоту арени — єдиний порятунок: пірнути на саме дно і перестрибнути гребінь через інерційний дельфінячий стрибок.
